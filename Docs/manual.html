第二章

角色與安全權限控制體系 (RBAC)

角色代碼 職稱 主要授權範圍
ADMIN 主委 / 管理員 全功能、全模組管理、系統參數維護、帳冊全面核銷。
RITUAL 科儀法師組長 規劃法會、現場登記、匯出疏文清冊、發布通告。
ACCOUNTANT 會計出納執事 法會/點燈開單收款、油香收據開立、支出審核登錄。
VOLUNTEER 臨櫃服務志工 臨櫃接待、查閱燈位狀態、查詢公開大榜。
GUEST 訪客善信 免密參訪、公開科儀日程、點燈大榜徵信、閱覽沿革。
第三章

身分驗證與安全入口 (login.html)

  • 執事人員登入： 輸入分派之帳號與密碼，點擊「🔑 執事人員登入」，取得安全 Token 後導向大廳。
  • 訪客免密瀏覽： 點擊「🙏 訪客信眾免密參訪」，以 GUEST 身分查閱公開大榜。
  • 內部測試快捷身分： 開發與展示期間，可點選下方快捷按鈕一鍵模擬各角色環境。
第四章

宮務大廳與動態看板 (index.html)

  • 動態營運指標： 即時呈現法會場次、神位已安奉數、物資在庫數與公帳當期結餘（權限卡控）。
  • 公告發布作業（限 ADMIN, RITUAL）： 點擊「➕ 發布新公告」，輸入標題、類別並可勾選「置頂」。
  • 公告全文查閱： 點擊「全文」開啟彈窗閱讀完整內容與執事簽章。
第五章

年度法會與科儀排程 (events.html)

  • 規劃新活動： 填寫代碼、名稱，選取國曆開經日期會自動連動農曆，並設定名額與每席緣金。
  • 受理登記： 支援 CRM 快速搜尋信眾帶入，選定祈福類別與普品代捐方式，自動計算緣金並產出流水號。
  • 匯出疏文清冊： 點擊「📜 下載疏文大榜清冊 (.txt)」，自動產出內嵌 UTF-8 BOM 之繁體中文檔案。
  • 影音與照片分享： 支援 YouTube 連結（自動轉化為播放器）與現場相片上傳。
第六章

神位點燈與視覺化排位 (lantern.html)

  • 九宮燈牆排位： 綠色為空位，金色為已安奉顯名位。
  • 臨櫃點燈： 點選空席位，填入善信生辰八字與地址，確認款項後開燈。
  • 查榜檢索： 信眾輸入姓名即可迅速定位燈位編號。
第七章

發心物資代捐與轉贈 (charity.html)

  • 入庫連動： 信眾報名法會勾選代捐時，系統自動將白米納入在庫數量。
  • 轉贈派發： 選定受贈社福機構、輸入包數並上傳簽收照片，完成除帳徵信。
第八章

公庫收支日記帳 (finance.html)

  • 香油開單： 登記收入，自動產生「五公緣字第 XXXXX 號」正式流水收據。
  • 支出核銷： 登記法會採購或修繕工程支出，自動扣減公帳結餘。
第九章

信眾家戶檔案 CRM (crm.html)

  • 以「戶」為單位建立戶長與家眷資料，自動換算出生年次之生肖與虛歲。
  • 法會與點燈臨櫃作業時，直接帶入整戶名冊，無需重複登打。
第十章

常見問題排除指南 (FAQ)

Q1：點擊「規劃新活動」或「受理登記」無反應？

因權限控管機制，志工（VOLUNTEER）與訪客（GUEST）無法操作此項目。請點擊首頁登出，改以具備權限之帳號登入。

Q2：疏文大榜純文字檔開啟呈現亂碼？

系統匯出時已加入 UTF-8 BOM 標記，在 Windows 記事本與 Mac 文字編輯器中均能直接正確顯示繁體中文。

Q3：大廳頂部橫額圖片顯示空白？

請確認 public/images/temple-banner.jpg 檔案是否存在；系統亦具備自動回退機制，若檔案遺失將自動切換為備用古剎圖。
